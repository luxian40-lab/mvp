🏢 Gestión de Organizaciones Cliente

¿Qué es una Organización?

Una Organización Cliente es la empresa, cooperativa o institución que contrata eki para capacitar a sus trabajadores. Es la entidad de nivel superior que agrupa estudiantes y cursos.

Cada organización tiene:

  • Sus propios estudiantes (solo ven cursos de su organización)
  • Sus propios cursos (contenido personalizado)
  • Sus propias campañas masivas
  • Sus propias plantillas de certificado
  • Un contacto principal (nombre, teléfono, email)

Crear una Organización

  1. Ve a Organizaciones Clientes en el menú lateral
  2. Haz clic en "Agregar Organización Cliente"
  3. Completa: Nombre, NIT, Contacto principal (nombre, teléfono, email)
  4. Marca como "Activa"
  5. Guarda. La organización ya puede recibir estudiantes y cursos

Asignar Cursos a una Organización

Cuando creas un curso, seleccionas la organización. Los estudiantes de esa organización solo verán los cursos asignados a ella.

⚠️ Importante: Si un curso no tiene organización asignada, será visible para TODOS los estudiantes. Siempre asigna una organización para mantener la separación de contenido.

📝 Guía Paso a Paso: Crear un Curso Completo

Paso 1: Crear el Curso

  1. Ve a Cursos → Agregar Curso
  2. Nombre: Nombre descriptivo (ej: "Manejo Integrado de Plagas del Café")
  3. Organización: Selecciona la organización cliente
  4. Emoji: Un emoji representativo (ej: 🌱, ☕, 🥑) — se muestra en WhatsApp
  5. Duración semanas: Estimado de duración (informativo)
  6. Orden: Número para ordenar la lista de cursos (1 = primero)
  7. Activo: ✅ Marcar para que sea visible a estudiantes
  8. Descripción: Breve descripción del curso (se muestra al inicio)

Paso 2: Agregar Módulos

Los módulos son las lecciones individuales. Se crean inline desde la misma página del curso.

  1. Número: Orden del módulo (1, 2, 3...). Los estudiantes los ven en este orden
  2. Título: Nombre corto de la lección (ej: "Control Biológico")
  3. Descripción: Resumen breve (se muestra antes del contenido)
  4. Contenido: El texto completo de la lección. Este es el contenido educativo que el estudiante lee por WhatsApp. Usa formato simple:
    • *texto* para negrilla
    • _texto_ para cursiva
    • Emojis para hacer el contenido visual y atractivo
  5. Video URL: Enlace al video educativo (YouTube, Vimeo, o URL directa). Se envía como multimedia por WhatsApp.
  6. Video archivo: Alternativamente, sube un video directamente. Se almacena en S3 y se envía con URL pública.
  7. Examen obligatorio: Si se marca, el estudiante debe aprobar un examen antes de poder avanzar al siguiente módulo
  8. Puntaje mínimo: Porcentaje mínimo para aprobar el examen obligatorio (ej: 60%)
💡 Tip de contenido: WhatsApp tiene un límite de ~1600 caracteres por mensaje. Si el contenido del módulo es muy largo, el sistema lo divide automáticamente en múltiples mensajes. Pero intenta mantener cada módulo entre 500-1500 caracteres para mejor experiencia.

Paso 3: Configurar Preguntas de Evaluación

Cada módulo puede tener una pregunta de evaluación que el estudiante debe responder al completar el módulo:

  • Pregunta con opciones: El estudiante elige A, B, C o D. Se evalúa automáticamente.
  • Pregunta abierta (IA): Sin opciones definidas, la IA evalúa la respuesta del estudiante.

Para agregar preguntas, ve a Preguntas de Módulo en el admin y vincúlalas al módulo correspondiente.

💡 Tip: Si un módulo no tiene preguntas configuradas, el estudiante avanza directamente al siguiente módulo al presionar el botón "Continuar".

Paso 4: Agregar Multimedia

Cada módulo puede tener archivos multimedia adjuntos:

  1. Ve a Archivos Multimedia en el admin
  2. Selecciona el Módulo al que pertenece
  3. Sube el archivo: imagen, video, PDF, infografía o audio
  4. El sistema lo almacena en S3 y genera URL pública para envío por WhatsApp
  5. Al estudiar el módulo, el primer archivo de tipo imagen/video se envía automáticamente como media adjunta al contenido
💡 Formatos soportados:
  • Imágenes: JPG, PNG, WebP (máx 5MB para WhatsApp)
  • Videos: MP4, 3GP (máx 16MB para WhatsApp)
  • Documentos: PDF (máx 100MB)
  • Audio: MP3, OGG, WAV (máx 16MB)

🎓 Certificados Digitales — Guía Completa

¿Cómo funciona la generación automática?

Cuando un estudiante completa todos los módulos de un curso, el sistema automáticamente:

  1. Calcula la calificación final basada en preguntas respondidas correctamente
  2. Busca la plantilla de certificado activa: primero por curso específico, luego por cliente, luego la por defecto
  3. Genera la imagen del certificado con el nombre del estudiante, calificación, fechas
  4. Lo sube a S3 (bucket: eki-produccion)
  5. Genera un código de verificación único (formato: EKI-XXXX-YYYY-ZZZZ)
  6. Envía la imagen por WhatsApp al estudiante
  7. Incluye URL de verificación pública

Configurar Plantilla de Certificado

  1. Ve a Plantillas de Certificado en el admin
  2. Crea una nueva plantilla o edita la existente
  3. URL plantilla imagen: URL de S3 donde está la imagen base del certificado (con marcadores de color para posición de texto)
  4. O sube archivo: Imagen o PDF que sirve como fondo
  5. Selecciona el Curso específico para esta plantilla (el certificado se generará automáticamente al completar ese curso)
  6. Si no asignas curso, marca como "Por defecto" para que se use como plantilla general
  7. Marca como "Activa"
💡 Sistema de Marcadores RGB: La plantilla imagen puede tener píxeles de colores específicos que el sistema detecta automáticamente para posicionar el texto:
  • ⚪ Gris (128,128,128): Posición del nombre del estudiante
  • 🔴 Rojo puro (255,0,0): Posición de la cédula
  • 🔵 Azul puro (0,0,255): Posición del código QR
El sistema escanea la imagen, detecta los marcadores, y reemplaza esas áreas con el texto/QR correspondiente.

❓ Preguntas Frecuentes (FAQ)

Estudiantes

P: Un estudiante dice que no puede verificarse con su cédula.

R: Verifica en el admin que la cédula del estudiante esté correcta (solo números, sin puntos). Si está mal, edítala directamente en el admin y pídele que reintente.

P: Un estudiante cambió de número de teléfono.

R: Ve al admin, busca al estudiante, cambia su campo "Teléfono" al nuevo número (con formato 573XXXXXXXXX). El progreso se mantiene.

P: ¿Puedo eliminar un estudiante?

R: Sí, pero perderás todo su progreso, respuestas y certificados. Es mejor desactivarlo.

P: Un estudiante quiere reiniciar su progreso.

R: Ve a Progresos de Estudiante, busca el progreso del estudiante en el curso específico, y elimínalo. El estudiante puede volver a empezar desde el módulo 1.

Cursos y Contenido

P: ¿Puedo editar un curso mientras hay estudiantes activos?

R: Sí. Los cambios en el contenido del módulo se reflejan inmediatamente cuando el estudiante acceda a ese módulo. Los módulos ya completados no se ven afectados.

P: ¿Cuántos módulos debe tener un curso?

R: Recomendamos entre 5-10 módulos. Cada módulo debe poder leerse en 5-10 minutos por WhatsApp (500-1500 caracteres). Más módulos = más preguntas = calificación más precisa.

P: ¿Los videos se envían automáticamente?

R: Sí, si el módulo tiene video_url o video_archivo, se envía como media adjunta al contenido del módulo.

Problemas Técnicos

P: Los mensajes no llegan al estudiante.

R: Verifica en WhatsApp Logs si el mensaje fue enviado. Si tiene error, revisa los logs de Twilio en console.twilio.com. Causas comunes: número inválido, ventana de 24h expirada, saldo Twilio agotado.

P: Error 63019 — Media download failed.

R: Este error ocurre cuando Twilio no puede descargar un archivo multimedia (imagen/video). Verifica que el archivo exista en S3. El sistema usa URLs públicas directas de S3 (el bucket tiene ACL public-read), lo que elimina problemas de credenciales o URLs expiradas.

P: Error 63016 — Template not found.

R: El Content Template de Twilio no está aprobado o fue eliminado. Verifica en console.twilio.com → Content Templates.

P: El certificado no se genera.

R: Verifica: (1) El curso tiene una plantilla de certificado activa, (2) El progreso del estudiante está marcado como completado, (3) Hay una PlantillaCertificado con "por_defecto=True" y "activa=True".

P: La IA no responde bien.

R: Verifica que las variables de entorno OPENAI_API_KEY tengan saldo. El sistema usa OpenAI como proveedor principal y Cohere como fallback.
