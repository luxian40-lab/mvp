Flujo operativo: Captar → Enseñar → Retener

  1. Captar: Cliente (org) → usuarios portal → Nat/catálogo si aplica.
  2. Enseñar: Curso → módulos (Module Builder) → campaña o drip WA.
  3. Retener: Centro de Éxito · conversaciones · push · certificados · WhatsappLog.
El portal (/portal/login/) es solo para coordinadores B2B. El admin es solo staff eki (is_staff).

Cursos y Module Builder

Ficha curso: módulos, inscritos, % completados, botones Ver módulos y Module Builder.

Listado módulos: columna Builder; micros en Borrador si no hay pasos activos.

Video WA: H.264+AAC. Error 63021 = codec; 63019 = URL/MIME.

Publicar módulos WhatsApp

  1. Abra la ficha del curso → panel «Módulos para WhatsApp» (semáforos).
  2. Cada módulo nuevo empieza en borrador (no se envía al campo).
  3. Complete Module Builder → checklist verde → Publicar ▶.
  4. Si el estudiante escribe listo y el siguiente está en borrador, recibe mensaje de espera (no error Twilio).
Cursos Clases / Aprende (Capital Humano, etc.) no usan esta puerta: el avance es en aula.

Atajo listado: Módulos en borrador

Campañas — wizard post-envío

  1. Ejecutar campaña (plantilla HX aprobada, audiencia validada).
  2. En la ficha: paso Revisar fallidos → tabla EnvioLog.
  3. CSV fallidos → corregir teléfonos → reenvío puntual o nueva campaña.

Calendario: /admin/calendario/

WhatsApp y WhatsappLog

WhatsappLog = auditoría técnica (estados Twilio, errores).

  • Filtro Código Twilio: 63019, 63021, 63005, opt-out…
  • Filtro Solo hoy para triage diario.
  • Columna Chat → inbox (mismo hilo que Conversaciones).

Plantillas Content: SID HX…, variables {{1}} secuenciales con samples.

Certificados

Herramienta: /admin/envio-certificados/ por org y curso.

Inicio avisa si hay certificados emitidos sin envío WA (Certs pend. WA).

Modo recomendado: plantilla diseno_eki (Pillow). Comando: asegurar_plantilla_certificado_default.

Conversaciones (inbox)

Pantalla completa: filtro por org, búsqueda por teléfono o nombre en la barra superior.

Desde ficha estudiante: Ver conversación. Nat usa número comercial aparte — no mezclar.

FAQ

¿No llega imagen/video por WA?

URL pública S3, MIME correcto (audio/mpeg). WhatsappLog → código 63019/63021.

¿Portal y admin comparten sesión?

No. Portal usa PortalUsuario; admin usa usuario Django staff.

¿Dónde está la doc GEI larga?
